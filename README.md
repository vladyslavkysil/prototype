# 🕵️‍♂️ Фоторобот: Інтерактивний прототип

Інтерактивний криміналістичний вебзастосунок, у якому слідчий разом зі свідком складає портрет підозрюваного з готових елементів рис обличчя та налаштувань.

---

## ✨ Основні можливості

- **Модульний конструктор обличчя:**
  - 👤 **Обличчя:** Овальне, Кругле, Квадратне
  - ✂️ **Зачіска:** Без волосся, Коротка, Довга, Чубчик
  - 〰️ **Брови:** Прямі, Дугоподібні, Похмурі
  - 👁️ **Очі:** Мигдалеподібні, Круглі, Вузькі
  - 👃 **Ніс:** Прямий, Картоплиною, Загострений
  - 👄 **Губи:** Тонкі, Усмішка, Повні
  - 🎨 **Колір шкіри:** палітра від світлого до смаглявого відтінків
- **Мікро-коригування повзунками:**
  - Точна зміна ширини носа
  - Зміна густоти та товщини брів
- **Динамічний словесний портрет:**
  - Автоматична генерація текстового опису для криміналістичного протоколу.
- **Експорт фоторобота:**
  - 📥 Завантаження у векторному форматі **SVG**
  - 🖼️ Завантаження у растровому форматі **PNG**
- **Архів справи:**
  - Збереження кількох версій портретів у поточну кримінальну справу з мініатюрами
  - Швидке повторне завантаження збереженого фоторобота в редактор
  - Збереження списку в `localStorage` браузера
- **Додаткові інструменти:**
  - 🎲 Генерація випадкового портрета
  - 🌙 / ☀️ Підтримка темної та світлої теми оформлення
  - 📱 Повна адаптивність під мобільні та десктопні пристрої

## 📁 Структура проєкту

Код розділено на логічні модулі для легкої підтримки та масштабування:

```text
prototype/
├── index.html        # Головна точка входу застосунку
├── fotorobot.html    # Додаткова точка доступу
├── css/
│   └── style.css     # Сучасні стилі, дизайн-система (змінні, темна тема)
├── js/
│   ├── data.js       # Конфігурація рис обличчя, кольорів і значень за замовчуванням
│   ├── renderer.js   # Генерація векторних SVG-елементів обличчя
│   └── app.js        # Управління станом, взаємодія з DOM, збереження та експорт
├── README.md         # Опис та інструкція користувача
└── .gitignore        # Файл виключення непотрібних файлів для Git
```

## 🚀 Як запустити локально

Оскільки проєкт використовує нативні ES-модулі JavaScript (`import`/`export`), для запуску достатньо будь-якого локального вебсервера:

### Варіант 1: Через VS Code Live Server
1. Відкрийте папку в Visual Studio Code.
2. Клацніть правою кнопкою миші на `index.html` і виберіть **"Open with Live Server"**.

### Варіант 2: Через Python
```bash
# Python 3
python -m http.server 8000
```
Після чого відкрийте в браузері: `http://localhost:8000`

### Варіант 3: Через Node.js (npx serve)
```bash
npx -y serve .
```
